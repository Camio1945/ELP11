# Module: Playlist

## Overview

Manages a playlist of video files for sequential playback. Supports auto-population from the directory of the currently opened video, manual drag-and-drop of files/folders onto the playlist tab, navigation between playlist items (prev/next), and a scrollable sidebar UI. Playlist state is in-memory only (not persisted).

## Platforms

- **PC** (Windows, Linux, macOS — file-based operations are cross-platform)

## Key Files

| File | Responsibility |
|------|---------------|
| `src/playlist.rs` | Core logic: `is_video_file()`, `scan_directory_for_videos()`, `parent_directory()`, supported extensions list |
| `src/playlist_view.rs` | Playlist sidebar UI: item list with current-playing highlight, clear button, empty state with hint |
| `src/app_handlers_playlist.rs` | Event handlers: clear, play item, prev/next, drop files, window file drop, auto-populate, open video |

## Public API

### Playlist Logic

- **`is_video_file(path: &Path) -> bool`** — Check file extension against 22 supported video formats
- **`scan_directory_for_videos(dir: &Path) -> Vec<String>`** — Non-recursive directory scan, sorted by name
- **`parent_directory(file_path: &str) -> Option<PathBuf>`** — Get the parent directory of a file

**Supported extensions:** mp4, mkv, avi, mov, wmv, flv, webm, m4v, mpg, mpeg, m2ts, ts, mts, vob, ogv, 3gp, 3g2, f4v, rm, rmvb, asf, divx, dv

### Playlist Actions

- **Play item by index:** Click a playlist entry to switch to that video
- **Prev/Next (PageUp/PageDown):** Navigate to previous or next video in the list
- **Clear:** Remove all items from the playlist
- **Drag-and-drop:** Drop video files or folders onto the playlist tab to populate the list
- **Window file drop:** Drop a file/folder on the window while playlist tab is active and empty
- **Auto-populate:** When a video is opened manually and the playlist is empty, scan its parent directory

## Dependencies

- **app_state:** `App` struct holds `playlist: Vec<String>` and `playlist_index: Option<usize>`
- **application core:** File opening logic (`open_video_file()`) is reused for playlist item playback

## Data Flow

```
Playlist population paths:

1. Auto-populate (when opening a video and playlist is empty):
   FileOpened → auto_populate_playlist(path)
     → parent_directory(path)
     → scan_directory_for_videos(dir) → sorted video paths
     → set playlist + find current file index

2. Drag-and-drop (files/folders dropped on playlist tab):
   PlaylistDropFiles(paths) → for each: is_video_file? or is_dir? scan
     → deduplicate + sort → replace playlist → play first item

3. Window file drop (when playlist tab active + empty):
   WindowFileDropped(path) → PlaylistDropFiles([path])

Navigation:
   PlayPlaylistItem(index)
     → playlist_index = Some(index)
     → open_video_file(path)
       → VideoState::Loading → Task::perform(Video::new) → FileOpened

   PlaylistPrev/PlaylistNext (PageUp/PageDown)
     → current_index - 1 or + 1 → PlayPlaylistItem(new_index)

   ClearPlaylist → playlist.clear(); playlist_index = None

State:
   playlist: Vec<String>          // all video file paths
   playlist_index: Option<usize>  // currently playing index (None if none)
```

### Playlist UI

- Displayed in the right sidebar's Playlist tab
- Orange/amber color theme
- Items are buttons showing file name; currently playing item highlighted in orange
- "Clear Playlist" button at top (only visible when non-empty)
- Empty state: music note emoji with hint text
