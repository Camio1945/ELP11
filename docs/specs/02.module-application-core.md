# Module: Application Core

## Overview

The application entry point and state management layer. This module defines the `App` struct (central application state), the `Message` enum (~40 variants covering all user and system interactions), the `dispatch()` method that routes messages to specialized handlers, keyboard shortcut processing, CLI argument parsing, and the Iced application bootstrap (subscriptions, theme, window settings).

## Platforms

- **PC** (Windows only for the binary application; the library crate works cross-platform)

## Key Files

| File | Responsibility |
|------|---------------|
| `src/main.rs` | Application entry point: `update`, `view`, `subscription` functions; Iced app bootstrap with window config |
| `src/app_state.rs` | `App` struct, `Message` enum, `VideoState` enum, `SidebarTab` enum; `App::default()`, `persist_current_position()`, `App::Drop` impl |
| `src/app_dispatch.rs` | `App::dispatch()` and two-tier routing: main → secondary (playlist) → tertiary (settings/sidebar) |
| `src/app_handlers.rs` | Handler methods for core playback: play/pause, seek, skip, frame step, volume, speed, fullscreen, content fit, file open, tick, save position |
| `src/app_keyboard.rs` | `App::handle_keyboard_event()` — maps Iced keyboard events to message handlers; arrow keys, space, character shortcuts, Home/End subtitle nav |
| `src/boot.rs` | CLI argument parsing (`parse_cli_args`), window icon loading, boot closure factory for initial app state with optional video/subtitle from CLI |

## Public API

### App State

- **`App`** — Central application state struct containing:
  - `video: VideoState` — Current video state (`NoVideo`, `Loading(path)`, `Ready(Video)`)
  - `position: f64` — Current playback position in seconds
  - `volume: f64` / `muted: bool` / `looping: bool` / `speed: f64` — Playback parameters
  - `fullscreen: bool` / `content_fit: iced::ContentFit` — Display settings
  - `subtitle_text: String` / `subtitle_image: Option<Handle>` — Active subtitle content
  - `dict_word: String` / `dict_chinese: String` / `dict_phonetic: String` / `dict_sections: Vec<DictSection>` — Dictionary state
  - `current_file_path: Option<String>` — Currently loaded file
  - `active_tab: SidebarTab` — Active sidebar tab (Dictionary / Settings / Playlist)
  - `settings: AppSettings` — Persistent configuration
  - `playlist: Vec<String>` / `playlist_index: Option<usize>` — Playlist state
  - `subtitle_cues: Vec<SubtitleCue>` — Parsed subtitle timing for Home/End navigation
  - `pending_resume: Option<f64>` — Deferred resume position applied on first frame

### Message Enum

~40 message variants organized by concern:
- **Playback:** `TogglePause`, `Seek`, `SeekRelease`, `SkipBack`, `SkipForward`, `FrameStepForward`, `FrameStepBackward`, `ToggleLoop`, `ToggleMute`, `SetVolume`, `AdjustVolume`, `SetSpeed`, `CycleContentFit`
- **File I/O:** `OpenFile`, `FilePicked`, `FileOpened`, `LoadSubtitle`, `SubtitlePicked`, `SubtitleExtracted`
- **Video Events:** `EndOfStream`, `NewFrame`, `PlaybackError`
- **Subtitles:** `SubtitleText`, `SubtitleImage`
- **Dictionary:** `SearchWord`, `DictionaryResult`, `CloseDictionary`
- **Window:** `ToggleFullscreen`, `KeyboardEvent`, `WindowOpened`, `WindowFileDropped`
- **Settings:** `SwitchSidebarTab`, `IncreaseSubtitleFont`, `DecreaseSubtitleFont`, `ToggleHistory`, `ClearHistory`, `RemoveHistoryItem`, `OpenHistoryItem`
- **Playlist:** `ClearPlaylist`, `PlayPlaylistItem`, `PlaylistPrev`, `PlaylistNext`, `PlaylistDropFiles`
- **System:** `Tick`, `SavePosition`

### CLI

```
elp11 [video_file] [subtitle_file]
```

Both arguments are optional. If a video is specified, it begins loading immediately on startup. An optional second argument specifies a subtitle file.

## Dependencies

- **iced_video_player** (library crate): Uses `Video`, `VideoPlayer`, `PgsImage`, `SubtitleStreamInfo` types
- **iced:** Application framework, widget system, window management, keyboard events
- **rfd:** Native file dialogs for open-file and load-subtitle
- **subtitle modules:** Discovery, extraction, parsing (see Subtitles module)
- **dict modules:** Dictionary lookup API (see Dictionary module)
- **playlist module:** Directory scanning and video detection
- **settings module:** Persistent configuration load/save

## Data Flow

```
main()
    │
    ├── parse_cli_args(args) → (video_arg, subtitle_arg)
    │
    ├── create_boot_closure() → App::default() + optional initial video load
    │
    └── iced::application(boot, update, view)
            │
            ├── Subscription batch:
            │     ├── keyboard::listen() → Message::KeyboardEvent
            │     ├── window::open_events() → Message::WindowOpened
            │     ├── window::events() → Message::WindowFileDropped (file drag-drop)
            │     ├── time::every(200ms) → Message::Tick (only when dict webview active)
            │     └── time::every(5s) → Message::SavePosition (only when video loaded)
            │
            ├── update(app, message) → App::dispatch(message) → Task<Message>
            │     │
            │     ├── dispatch() [main: playback, video, dictionary, keyboard]
            │     ├── dispatch_secondary() [playlist messages]
            │     └── dispatch_settings() [sidebar, settings, history messages]
            │
            └── view(app) → views::view(app) → Element tree
```

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Toggle pause |
| `Left/Right` | Skip back/forward 5s |
| `Up/Down` | Volume +/-0.05 (Ctrl: speed +/-0.25) |
| `Home/End` | Jump to previous/next subtitle cue |
| `PageUp/PageDown` | Previous/next playlist item |
| `Enter` or `F` | Toggle fullscreen |
| `M` | Toggle mute |
| `L` | Toggle loop |
| `[` / `]` | Decrease/increase speed |
| `,` / `.` | Frame step backward/forward |
| `O` | Open file dialog |
| `S` | Load subtitle dialog |
| `C` | Cycle content fit |
| `Escape` | Exit fullscreen, close dictionary, or no-op |

### Crash Resilience

Playback position is auto-saved every 5 seconds via the `SavePosition` subscription. The `Drop` impl on `App` also performs a best-effort final save on exit. Only meaningful position changes trigger disk writes to minimize I/O.
