# Module: Video Playback Engine

## Overview

Provides the core media playback and rendering pipeline. The `Video` struct manages a GStreamer `playbin` pipeline for decoding any supported media format, exposes a background worker thread that continuously pulls decoded video frames (NV12 format) from an `appsink`, and stores them in a shared frame buffer. The `VideoPlayer` widget integrates with Iced's renderer via a custom wgpu primitive (`VideoPrimitive`) that uploads frames to GPU textures and performs YUV-to-RGB conversion in a WGSL shader. AV sync correction is computed from the latency between frame arrival and rendering.

## Platforms

- **PC** (Windows, Linux, macOS — wherever GStreamer and wgpu are available)

## Public API

### `Video` (media handle)
- **`Video::new(uri: &url::Url) -> Result<Self>`** — Constructs a new video player from a URI. Initializes GStreamer, builds the `playbin` pipeline, starts playback.
- **`Video::set_paused(bool)`** — Pause / resume playback.
- **`Video::seek(position: Duration, accurate: bool) -> Result`** — Seek to a specific timestamp.
- **`Video::set_speed(f64) -> Result`** — Set playback speed multiplier.
- **`Video::set_volume(f64)`** / **`set_muted(bool)`** — Audio control.
- **`Video::set_looping(bool)`** — Enable/disable loop at end-of-stream.
- **`Video::set_subtitle_url(&url::Url) -> Result`** — Load an external subtitle file.
- **`Video::step_one_frame()`** — Advance one frame forward (when paused).
- **`Video::position() -> Duration`** / **`duration() -> Duration`** / **`paused() -> bool`** / **`looping() -> bool`** / **`framerate() -> f64`** — Read accessors.
- **`Video::size() -> iced::Size`** — Native video resolution.
- **`Video::subtitle_streams() -> Vec<SubtitleStreamInfo>`** — Metadata about embedded subtitle streams.
- **`Video::thumbnails(positions: &[Duration], size: iced::Size) -> Vec<iced::widget::image::Handle>`** — Generate thumbnail images.

### `VideoPlayer` (Iced widget)
- **`VideoPlayer::new(video: &Video) -> Self`** — Create a widget from a `Video` handle.
- **`.on_end_of_stream(Message)`** — Callback when playback reaches the end.
- **`.on_new_frame(Message)`** — Callback fired on every new rendered frame.
- **`.on_subtitle_text(Fn)`** / **`.on_subtitle_image(Message)`** — Subtitle callbacks for text and bitmap (PGS) subtitles.
- **`.on_error(Message)`** — Callback for playback errors.
- **`.content_fit(ContentFit)`** — How the video scales within its layout bounds.
- **`.on_mouse_wheel_scrolled(Message)`** — Mouse wheel callback (used for volume adjustment).

## Dependencies

- **GStreamer (runtime):** All media decoding and demuxing is handled by GStreamer's `playbin` pipeline
- **iced_wgpu:** `VideoPipeline` implements `iced_wgpu::primitive::Pipeline` to integrate with Iced's wgpu renderer
- **gstreamer-video:** `VideoMeta` for reading NV12 frame stride and plane offsets

## Data Flow

```
GStreamer Pipeline (playbin)
    │
    ├── video-sink: videoscale → videoconvert → appsink (iced_video)
    │       │
    │       ▼
    │   Background worker thread: pull_sample() → Arc<Mutex<Frame>>
    │       │
    │       ▼   (upload_frame = true)
    │   VideoPlayer.update(): drain bus → fire callbacks → request_redraw()
    │       │
    │       ▼
    │   VideoPrimitive.prepare(): lock frame → queue.write_texture(Y, UV planes)
    │       │
    │       ▼
    │   VideoPipeline.draw(): bind groups → render pass → WGSL shader
    │       │
    │       ▼
    │   GPU: YUV→RGB (BT.709) → output framebuffer
    │
    ├── text-sink: appsink (iced_text)
    │       │
    │       ▼
    │   Worker thread: pull_text_sample() → Arc<Mutex<Option<String>>>
    │       │
    │       ▼
    │   VideoPlayer: on_subtitle_text callback → app_state.subtitle_text
    │
    └── AV sync: draw() computes latency → running average → pipeline av-offset
```

### AV Sync

Each frame is timestamped on arrival (`last_frame_time`) and the time delta between arrival and usage in `draw()` is averaged. Every 128 frames, the running average is applied as `av-offset` on the GStreamer pipeline to keep audio synchronized with the displayed video.
