# Module: Subtitles

## Overview

Comprehensive subtitle support for the video player. The module handles external subtitle auto-discovery (matching video filename), embedded subtitle stream extraction (via ffmpeg), parsing of multiple subtitle formats (SRT, VTT, ASS/SSA), PGS bitmap decoding with OCR (Windows.Media.Ocr), on-screen rendering with clickable word tokens, and keyboard-based subtitle-to-subtitle navigation (Home/End keys).

## Platforms

- **PC** (Windows — PGS OCR requires Windows 10+; text subtitle handling is cross-platform)

## Key Files

| File | Responsibility |
|------|---------------|
| `src/subtitle_discovery.rs` | Auto-detect external subtitle files matching a video's filename stem; prefers English (default) subtitles |
| `src/subtitle_extract.rs` | Extract embedded subtitle streams to external SRT using ffmpeg; includes PGS→SRT pipeline with built-in Windows OCR |
| `src/subtitle_parse.rs` | Parse SRT, VTT, ASS/SSA files into `Vec<SubtitleCue>` (timed start/end pairs) for navigation |
| `src/subtitle_view.rs` | Render subtitle text as a clickable overlay: tokenize text into words/punctuation, wrap lines, make each word clickable for dictionary lookup |
| `src/pgs.rs` | Minimal PGS (Blu-ray Presentation Graphic Stream) decoder: parse `.sup` display sets, decode RLE bitmaps to RGBA with position metadata |
| `src/app_handlers_subtitle.rs` | Subtitle event handlers: text/image reception, auto-apply subtitle on file open, external subtitle loading, embedded extraction orchestration, Home/End navigation logic |

## Subtitle Loading Priority

When a video file is opened, subtitles are loaded with this priority:

1. **Explicit CLI argument** (`--subtitle` passed at startup)
2. **External English subtitle file** found next to the video (discovery by filename matching)
3. **Embedded English stream extraction** (text-based → direct ffmpeg conversion; PGS bitmap → ffmpeg + OCR → SRT)

## Public API

### Subtitle Discovery
- **`find_english_subtitle_file(video_path: &str) -> Option<PathBuf>`** — Scan the video's directory for matching subtitle files; prefers default/English

### Subtitle Extraction
- **`extract_embedded_subtitle(video_path: &str, sub_index: i32, is_pgs: bool) -> Result<PathBuf, String>`** — Extract embedded stream to SRT; caches result (skips if `.en.srt` already exists)

### Subtitle Parsing
- **`parse_subtitle_file(path: &Path) -> Vec<SubtitleCue>`** — Parse SRT/VTT/ASS/SSA into sorted timing cues
- **`SubtitleCue { start: f64, end: f64 }`** — Timed subtitle cue for navigation

### PGS Decoder
- **`PgsImage { rgba, width, height, x, y, frame_width, frame_height }`** — Decoded PGS bitmap with position
- **`parse_sup(data: &[u8]) -> Vec<PgsDisplaySet>`** — Parse `.sup` stream into timestamped display sets

### Subtitle Rendering
- **`build_subtitle_with_clickable_words(text: &str, font_size: f32) -> Element<Message>`** — Render subtitle text as clickable tokens
- **`clean_subtitle_text(raw: &str) -> String`** — Strip HTML tags and decode HTML entities from subtitle text

### Subtitle Navigation (Home/End keys)
- **Home key:** Jump to start of current subtitle cue; double-press within 1s steps back one extra cue
- **End key:** Jump to start of next subtitle cue
- In gaps between cues: Home goes to nearest preceding cue start; End goes to first cue ahead

## Dependencies

- **iced_video_player (pgs module):** PGS parsing library exposed via the library crate
- **ffmpeg (external):** Required on PATH for embedded subtitle extraction
- **Windows.Media.Ocr (Windows 10+):** OCR engine for converting PGS bitmap subtitles to text
- **image crate:** PGS bitmap preprocessing (luminance extraction, upscaling for OCR)
- **application core:** `App` state (subtitle_text, subtitle_image, subtitle_cues, last_home_seek)

## Data Flow

```
Video Opened → apply_subtitle_auto()
    │
    ├── (1) CLI subtitle? → load_subtitle_file() directly
    │
    ├── (2) External English subtitle found? → load_subtitle_file()
    │         │
    │         ├── parse_subtitle_file() → subtitle_cues (Home/End nav)
    │         └── video.set_subtitle_url() → GStreamer text-sink → Worker thread
    │
    └── (3) Embedded English stream? → Task::perform(extract_embedded_subtitle)
                │
                ├── Text-based: ffmpeg -map 0:s:N -c:s srt → .en.srt
                │
                └── PGS bitmap:
                      ffmpeg -map 0:s:N -c copy → .sup
                      → pgs::parse_sup() → Vec<PgsDisplaySet>
                      → WinOcr::recognize() per display set
                      → merge consecutive identical lines
                      → write .en.srt

Rendering:
    GStreamer text-sink → worker thread → VideoPlayer
        └── on_subtitle_text callback → clean_subtitle_text()
            → subtitle_view::build_subtitle_with_clickable_words()
                ├── tokenize: alphabetic words vs punctuation
                ├── wrap into lines (max 80 chars)
                └── each word → MouseArea(on_press: SearchWord) → dictionary lookup

    GStreamer subpicture-sink (PGS) → worker thread → VideoPlayer
        └── on_subtitle_image callback → PgsImage → resize 55% → Iced Image
```

### PGS OCR Pipeline

```
.sup stream → parse_sup() → PgsDisplaySet[]
    │
    ▼
For each display set with image:
    RGBA pixels → luminance extraction (ink=black on white bg)
    → upscale 3x (CatmullRom) → BMP encoding
    → InMemoryRandomAccessStream → BitmapDecoder
    → SoftwareBitmap → OcrEngine::RecognizeAsync()
    → text result
    │
    ▼
Merge consecutive identical lines → SRT entries → write .en.srt
```
