# Module: UI Components

## Overview

Provides the visual layer of the application: top-level view composition, reusable custom widget factories (transport controls, toolbar buttons), a multi-accent color design system with distinct palettes per feature area, inline SVG icon definitions, and text formatting utilities. All UI styling uses Iced's built-in styling traits with custom style functions.

## Platforms

- **PC** (Windows, Linux, macOS — Iced widgets are cross-platform)

## Key Files

| File | Responsibility |
|------|---------------|
| `src/views.rs` | Top-level view composition: toolbar, seek bar, transport controls, video area, subtitle overlay, loading/no-video screens |
| `src/widgets.rs` | Reusable widget factories: skip-back/forward, play/pause, frame step, loop, mute, content-fit, fullscreen buttons using inline SVG icons |
| `src/icons.rs` | Inline SVG icon data constants (skip, play, pause, frame step) and `svg_handle()` builder |
| `src/text_utils.rs` | `format_time()` for HH:MM:SS display, `clean_subtitle_text()` for stripping HTML tags/entities, `STOP_WORDS` list |
| `src/styles/mod.rs` | Color palette constants (base neutrals + per-section accent colors: green, purple, blue, orange, teal) |
| `src/styles/buttons.rs` | Button style functions: teal (toolbar), purple, green (play/pause), active, mute, loop, rewind/forward, step, fullscreen, secondary, danger, text-link |
| `src/styles/surfaces.rs` | Container/surface style functions: toolbar bg, control panel, video surface, sidebar, sidebar header/body, settings containers, dict containers, playlist containers, placeholder, scrollbar |
| `src/styles/widgets.rs` | Slider and pick-list style functions |

## Color Design System

The application uses a **multi-accent dark theme** where each major feature area has its own color identity:

| Area | Accent Color | Hex |
|------|-------------|-----|
| Video controls | Green | `#1ed760` |
| Dictionary tab | Purple/Violet | `#9c63dd` |
| Settings tab | Blue | `#4192f7` |
| Playlist tab | Orange/Amber | `#f99220` |
| Main toolbar | Teal | `#41c7b5` |
| Errors | Red | `#f3727f` |

**Base neutrals:**
- Background: `#121212` (deepest), Surface: `#181818` (cards), Interactive: `#1f1f1f`
- Text: White, Silver (`#b3b3b3`), Near-white (`#cbcbcb`), Muted (`#8c8c94`)
- Border: `#4d4d4d`

Each accent has hover and pressed variants for interactive feedback.

## Widget Design

### Transport Controls

All transport buttons use inline SVG icons (24×24 viewBox, centered), sized to 22px, in 32px-tall pill-shaped buttons:

| Button | Icon | Message |
|--------|------|---------|
| Skip back 10s / 5s | Double/single left arrow | `SkipBack(10)` / `SkipBack(5)` |
| Play/Pause | Triangle (play) / Double bar (pause) | `TogglePause` |
| Skip forward 5s / 10s | Single/double right arrow | `SkipForward(5)` / `SkipForward(10)` |
| Frame step | Vertical bar + triangle | `FrameStepForward` |

Play/Pause is the hero button: 36×36px, circular, green accent.

### Utility Controls

| Button | Style | Message |
|--------|-------|---------|
| Loop | Toggle: active (green) / inactive | `ToggleLoop` |
| Mute | Toggle: muted (gray) / unmuted | `ToggleMute` |
| Content fit | Label showing current fit mode | `CycleContentFit` |
| Fullscreen | Unicode arrow icon | `ToggleFullscreen` |

### Layout Structure

```
Container (dark background #121212)
├── Toolbar: [OPEN] [SUBTITLE...] ... [00:00 / 00:00]
├── Row
│   ├── Player Column
│   │   ├── Video Area (with subtitle overlay Stack)
│   │   └── Bottom Panel
│   │       ├── Seek Bar (Slider)
│   │       └── Controls Row (transport + utility)
│   └── Sidebar (360px, right)
│       ├── Tab Bar: [Dictionary] [Settings] [Playlist]
│       └── Tab Content (Scrollable)
```

### Subtitle Overlay

Subtitles are rendered as a `Stack` layer on top of the video:
- Text subtitles: white text on semi-transparent black background, rounded border, centered
- Each word is tokenized and wrapped into clickable `MouseArea` widgets
- PGS bitmap subtitles: scaled to 55% of original width, centered at bottom
- Font size is adjustable (12–48px, default 20px)

## Dependencies

- **iced:** Widgets (Button, Container, Column, Row, Slider, PickList, Text, Image, Svg, Stack, MouseArea, Scrollable, Space)
- **iced_video_player:** `VideoPlayer` widget, `Video` handle, `pgs::PgsImage`
- **app_state:** `Message` enum, `App` struct, `SidebarTab` enum

## Text Utilities

- **`format_time(secs: f64) -> String`** — Format seconds as `M:SS` or `H:MM:SS`
- **`clean_subtitle_text(raw: &str) -> String`** — Remove HTML formatting tags (`<b>`, `<i>`, `<font>`, etc.), decode entities (`&amp;`, `&lt;`, `&apos;`), convert SSA newlines (`\N`, `\n`, `\h`)
- **`STOP_WORDS`** — 80+ common English stop words (kept for potential vocabulary extraction; currently unused)
