# Module: Dictionary

## Overview

Integrated English dictionary lookup triggered by clicking words in subtitles. The module provides multiple lookup backends: **FreeDictionary API** (dictionaryapi.dev) for English definitions with phonetics and examples, **MyMemory** for Chinese translation, and **Youdao Dictionary** (dict.youdao.com) embedded via a native child WebView (wry on Windows) for the richest results. The dictionary sidebar displays results with a multi-accent purple theme and is accessible from the right sidebar's Dictionary tab.

## Platforms

- **PC** (Windows — WebView uses wry/Win32; FreeDictionary and MyMemory are cross-platform)

| `src/dict_webview/scripts.rs` | JavaScript payloads: darkreader.js, dark CSS override, mobile user-agent, search injection script |

## Public API

### API-based Lookup (dict.rs)

- **`lookup(word: &str) -> DictResult`** — Combined English definitions + Chinese translation
- **`DictResult { word, chinese, phonetic, sections, examples, error }`** — Unified result type
- **`DictSection { part_of_speech, definitions: Vec<(String, Option<String>)> }`** — Definitions grouped by POS

**APIs used:**
- `https://api.dictionaryapi.dev/api/v2/entries/en/{word}` — FreeDictionary for English definitions
- `https://api.mymemory.translated.net/get?q={word}&langpair=en|zh-CN` — MyMemory for Chinese translation
- Both with 10-second timeout; errors are silently handled (best-effort)

### WebView-based Lookup (dict_webview/)

- **`tick(is_dict_active, dict_word, window_title)`** — Drive the webview state machine (called on every 200ms tick)
- **`has_webview() -> bool`** — Whether a webview is currently alive
- **`destroy()`** — Tear down the webview (called on app exit)

**WebView architecture:**
- Loads `https://dict.youdao.com/m/result?word={word}&lang=en` (mobile version) once
- Subsequent word searches inject JavaScript to fill `#search_input` and trigger search (no page reload)
- `darkreader.js` and aggressive CSS override injected on page load for dark theme
- Webview is created as a child of a transparent popup HWND, sized/positioned to cover the dictionary tab body
- When word is empty or non-dictionary tab is selected, popup is moved off-screen (-32000, -32000)

## Dependencies

- **ureq:** HTTP client for FreeDictionary and MyMemory API calls
- **serde_json:** JSON parsing for API responses
- **wry (0.43):** WebView library for embedding Youdao dictionary browser
- **raw-window-handle:** HWND access for window management
- **windows crate:** Win32 API calls for window find/size/position
- **app_state:** `App` struct holds dict_word, dict_chinese, dict_phonetic, dict_sections, dict_examples, dict_error

## Data Flow

```
User clicks word in subtitle → Message::SearchWord(word)
    │
    ▼
handle_search_word() → set dict_word, switch to Dictionary tab, clear previous results
    │
    ▼
Tick (every 200ms) → dict_webview::tick(is_dict_active, Some(word), window_title)
    │
    ├── First call: create_popup() + build_and_attach_webview()
    │     ├── wry::WebViewBuilder::new_as_child(popup HWND)
    │     ├── .with_url("https://dict.youdao.com/m/result?word={word}&lang=en")
    │     ├── .with_initialization_script(DARKREADER_JS)
    │     └── .with_on_page_load_handler → PAGE_LOADED = true
    │
    ├── Word change while webview alive:
    │     wv.evaluate_script(search_script(new_word))
    │     → fills #search_input, dispatches Enter keypress
    │
    └── Page loaded event:
          wv.evaluate_script(DARK_OVERRIDE_JS)  // inject dark CSS
          wv.evaluate_script(search_script(current_word))  // search on first load

    └── Popup positioning: compute_popup_rect() calculates sidebar bounds
          → move_popup() or off-screen hide
```

### API-based Flow (legacy/fallback)

```
handle_search_word() → (WebView handles in primary path)
    │
    ▼ (legacy path)
dict::lookup(word)
    ├── MyMemory API → Chinese translation → clean_translation()
    └── FreeDictionary API → English definitions → extract_dict_info()
    → DictResult → Message::DictionaryResult → handle_dictionary_result()
```
