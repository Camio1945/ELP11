# Module: Settings & Persistence

## Overview

Manages persistent application configuration stored as JSON on disk. On Windows the config file lives at `%APPDATA%\ELP11\settings.json`; on other platforms at `$HOME/.config/ELP11/settings.json`. The module handles config loading with graceful fallback to defaults, atomic writes for crash safety, and provides user-facing settings UI (subtitle font size, file-open history management).

## Platforms

- **PC** (Windows, Linux, macOS)

## Key Files

| File | Responsibility |
|------|---------------|
| `src/settings.rs` | `AppSettings` struct, config file path resolution, `load()` / `save()` functions, atomic write with temp file + rename |
| `src/app_handlers_settings.rs` | Handler methods for settings-related messages: font size adjustment, history toggle, history management |
| `src/dict_view_settings.rs` | Settings tab UI: subtitle font size controls, history section with file list and max-items config |

## Public API

### `AppSettings` struct

```rust
pub struct AppSettings {
    pub subtitle_font_size: f32,       // default: 20.0, range: 12.0–48.0
    pub history_enabled: bool,         // default: true
    pub max_history_items: usize,      // default: 100, range: 10–1000
    pub recent_files: Vec<String>,     // most-recent first
    pub active_tab: SidebarTab,        // last active sidebar tab
    pub playback_positions: HashMap<String, f64>, // keyed by file path
}
```

### Key Methods

- **`load() -> AppSettings`** — Load from disk; returns defaults if file missing, unreadable, or invalid JSON
- **`save(&AppSettings)`** — Atomic write (temp file + rename); falls back to direct write on failure
- **`increase_font()` / `decrease_font()`** — Adjust subtitle font size in 2px steps
- **`increase_max_history()` / `decrease_max_history()`** — Adjust max history items in 10-item steps; auto-truncates lists
- **`add_recent_file(path)`** — Add path to front of recent files, deduplicate, trim to max
- **`set_resume_position(path, position)`** — Record playback position for crash recovery
- **`prune_resume_positions()`** — Remove position entries for files no longer in recent list

### Settings UI (in dictionary sidebar Settings tab)

- Subtitle font size adjustment with +/- buttons and current value display
- History toggle (enable/disable) with clear-all button
- Max history items adjustment
- Scrollable list of recently opened files, each clickable to re-open, with individual remove buttons

## Dependencies

- **serde / serde_json:** Serialization/deserialization of settings to JSON
- **app_state:** `SidebarTab` enum used in settings; `App.` borrows `AppSettings`

## Data Flow

```
App Startup:
    App::default() → settings::load() → AppSettings
        │
        ▼
    App.settings (held in memory for read access)

Periodic Save (every 5s while video loaded):
    Message::SavePosition → App::persist_current_position()
        │
        ├── Check history_enabled, valid file path, position > 0
        ├── Skip if position unchanged (< 0.5s delta)
        └── settings.set_resume_position() → settings::save(&self.settings)

On Settings Change:
    User action → Message → handle_*_settings() → settings::save()

App Drop:
    App::Drop → persist_current_position() → settings::save()

Atomic Write:
    serde_json::to_string_pretty() → write(settings.json.tmp) → rename(settings.json)
    │                                                            │
    └── Failed rename: remove temp file, fallback to direct write
```

### Config File Location

- **Windows:** `%APPDATA%\ELP11\settings.json`
- **Linux/macOS:** `$HOME/.config/ELP11/settings.json`
- Directory is auto-created on first save
